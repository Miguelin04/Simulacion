# Simulación de Fila en un Supermercado

# Integrantes: 
* Miguel Luna
* Isabel Morocho
* Leonardo Peralta
* Santiago Tamayo

## Descripción general:

Este proyecto presenta una simulación del proceso de atención en las cajas de un supermercado. Cuyo objetivo es determinar en qué caja conviene ingresar para reducir el tiempo total de espera, considerando factores como el número de personas en la fila, la cantidad de artículos por cliente y la velocidad de atención de cada cajero.

Asimismo, se incorpora una **Caja Express** con un límite de 10 artículos por persona, con el fin de evaluar si realmente ofrece un mejor rendimiento o si su popularidad la hace menos eficiente que las cajas regulares.
